Logowanie i rejestracja

Jak się zarejestrować?

  1. Kliknij przycisk Rejestracja w prawym górnym rogu.
  2. Wpisz wybrany login i hasło.
  3. Kliknij Zarejestruj się.
  4. Po udanej rejestracji możesz się zalogować.
💡 Login musi być unikalny w systemie.

Jak się zalogować?

  1. Kliknij przycisk Logowanie w górnym pasku.
  2. Wpisz swój login i hasło.
  3. Naciśnij Enter lub kliknij Zaloguj się.
  4. Po zalogowaniu w pasku pojawi się Twoja nazwa i przycisk Wyloguj.

Skocznie narciarskie

Przeglądanie skoczni

  • Lista wszystkich skoczni z nazwą, lokalizacją i punktem K.
  • Kolumna 🏅 Rekord pokazuje najlepszy wynik i nick gracza.
  • Kliknij nazwę skoczni lub przycisk 🏆 Rekordy, aby zobaczyć wyniki wszystkich graczy na tej skoczni.

Dodawanie wyniku na skoczni

  1. Otwórz modal rekordów skoczni (przycisk 🏆 Rekordy).
  2. Kliknij + Dodaj wynik (widoczny po zalogowaniu).
  3. Wybierz gracza, wpisz odległość w metrach, datę skoku.
  4. Opcjonalnie: zaznacz Upadek i wklej link do powtórki.
  5. Kliknij Dodaj.
💡 Wynik ponad punkt K oznaczony jest odznaką ✓ K.
🛡️ Tylko Admin

Zarządzanie skoczniami

  • + Dodaj skocznię – uzupełnij nazwę, lokalizację i punkt K.
  • ✏️ Edytuj – zmień dane istniejącej skoczni.
  • 🗑️ Usuń – trwale usuwa skocznię z bazy.
⚠️ Usunięcie skoczni może wpłynąć na powiązane wyniki!

Gracze – ranking

Jak działa ranking?

Gracze są sortowani według sumy rekordów – czyli sumy najdłuższych skoków z każdej skoczni z osobna.

🥇 Miejsce 1
🥈 Miejsce 2
🥉 Miejsce 3
4, 5, 6... reszta
💡 Suma rekordów = najdłuższy skok z każdej skoczni zsumowany razem.

Wyniki gracza

Kliknij odznakę z liczbą skoczni lub przycisk 🏆 Wyniki przy graczu, aby zobaczyć jego pełną historię skoków pogrupowaną po skoczniach.

🛡️ Tylko Admin

Zarządzanie graczami

  • + Dodaj gracza – podaj login gracza.
  • ✏️ Edytuj – zmień login gracza.
  • 🗑️ Usuń – usuwa gracza z rankingu.

Wyniki skoków

Sekcja Wyniki to centralna tabela wszystkich skoków w systemie (dostępna tylko dla admina w nawigacji).

✓ K Skok przekroczył punkt K skoczni
💥 Upadek Lądowanie zakończone upadkiem
✓ OK Poprawne lądowanie
▶ Powtórka Link do nagrania skoku (klikalne)
💬 Komentarze Otwiera komentarze powiązane z wynikiem
🛡️ Tylko Admin

Dodawanie wyniku

  1. Kliknij + Dodaj wynik.
  2. Wybierz gracza i skocznię z list rozwijanych.
  3. Podaj odległość (metry), datę i opcjonalnie link do powtórki.
  4. Zaznacz czy upadek jeśli gracz upadł.
  5. Kliknij Dodaj.
🛡️ Tylko Admin

Edycja i usuwanie

  • ✏️ przy wierszu otwiera formularz edycji wyniku.
  • 🗑️ trwale usuwa wynik – pojawi się prośba o potwierdzenie.
💬

Komentarze

Przeglądanie komentarzy

  • Tabela wyświetla treść, ID wyniku i ID użytkownika.
  • Filtr „Filtruj po ID wyniku" – wpisz numer i kliknij Szukaj, aby zobaczyć komentarze do konkretnego wyniku.
  • Resetuj – przywraca pełną listę.
🛡️ Tylko Admin

Zarządzanie komentarzami

  • + Dodaj komentarz – podaj treść, ID wyniku i ID użytkownika.
  • ✏️ Edytuj – zmień treść lub powiązanie.
  • 🗑️ Usuń – usuwa komentarz.
💡 Komentarze są też dostępne z poziomu tabeli wyników (przycisk 💬).
